# Dataset Directory: Student Performance

This directory stores the raw data files for the Student Performance Analysis Dashboard project.

## Provenance and Source Attribution

- **Primary Benchmark Reference**: UCI Machine Learning Repository
  - Dataset Name: Student Performance Dataset
  - Source URI: [https://archive.ics.uci.edu/dataset/320/student+performance](https://archive.ics.uci.edu/dataset/320/student+performance)
  - DOI / Citation: Cortez, P., & Silva, A. (2008). *Using Data Mining to Predict Secondary School Student Performance*. In A. Brito & J. Teixeira (Eds.), Proceedings of 5th FUture BUsiness TEChnology Conference (FUBUTEC 2008), pp. 5-12, Porto, Portugal, EUROSIS, ISBN 978-9077381-39-7.
- **Secondary Access / Mirror Source**: Kaggle Mirror
  - Source URI: [https://www.kaggle.com/dskagglemt/student-performance-data-set/metadata](https://www.kaggle.com/dskagglemt/student-performance-data-set/metadata)

## Files Contained

1. `student-mat.csv`: Records for students enrolled in Mathematics course (395 observations, 33 attributes, semicolon `;` delimited).
2. `student-por.csv`: Records for students enrolled in Portuguese language course (649 observations, 33 attributes, semicolon `;` delimited).
3. `student.txt`: Original attribute metadata and description from the researchers.
4. `student-merge.R`: Original R script demonstrating merging logic for the 382 overlapping students present in both courses.

## Ethical Note and Data Privacy

- This is a fully anonymized research dataset collected in two Portuguese secondary schools (Gabriel Pereira and Mousinho da Silveira).
- No personally identifiable information (PII) such as student names, identification numbers, addresses, phone numbers, or emails are present.
- The data is utilized solely for academic and open-source educational evaluation.
